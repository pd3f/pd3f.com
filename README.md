# [pd3f.com](https://pd3f.com)

Website to Website to advertise & document [pd3f](https://github.com/pd3f).

Based on the Book Template of [Academic Website Builder](https://sourcethemes.com/academic/) with the [academic-starter-book](https://github.com/sourcethemes/academic-starter-book).

## Development

`./local.sh` serves the site at <http://localhost:1316>, `hugo` builds it into `public/`.
Both need the extended edition of Hugo and Go, which Hugo uses to download the theme.
`layouts/` overrides the theme's templates that current Hugo can't render.
